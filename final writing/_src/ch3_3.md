# 3.3 Environmental Impact

The environmental cost of this work is the electricity used to train and evaluate the models, and it is small because every model involved is small. All training and local inference ran on one RTX 4060 with a rated board power of 115 W {cite:nvidia_rtx4060}. Taking rated power times measured GPU hours, which overstates the true draw, training the final detector used about 0.017 kWh and the RoBERTa-large alternative about 0.124 kWh. The heaviest items were generation for fourteen configurations over 300 conversations each and the repeated fine-tuning runs, a few kilowatt-hours in total, comparable to running a desktop for a few days. No cloud GPU was rented and nothing was trained from scratch.

The design choice examined in this thesis also has a direct environmental consequence. Within statistical error the system matches the AI-judge scores of a single model with 1.9 times its parameters while using 38% less GPU memory, 3.40 GB against 5.47 GB, at the same time per generated token, so a service that would otherwise need a data-centre GPU can run on a mid-range consumer card. Three properties reduce the footprint further: RoBERTa-base at 125 million parameters gives the same reply quality as RoBERTa-large at 355 million, so the larger detector's extra energy buys nothing; the generator is quantised to 4 bits; and because everything runs locally, no message travels to a data centre and back.

The project also bought no new hardware: it ran on a computer the team already owned, and the 8 GB limit was set precisely so that none would be needed.
