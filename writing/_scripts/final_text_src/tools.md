The system was implemented in Python 3.10 using PyTorch 2.5.1 {cite:paszke2019pytorch} and Hugging Face Transformers 5.16.1 {cite:wolf2020transformers}. Transformers provides pre-trained encoders, namely RoBERTa {cite:liu2019roberta}, BERT {cite:devlin2019} and ELECTRA, and instruction-tuned decoders, namely Phi-4-mini {cite:abouelenin2025phi4mini}, Qwen2.5 {cite:qwen2024} and Gemma-3, behind a common interface, which allowed design alternatives to be exchanged without rewriting code. The bitsandbytes library provided 4-bit NF4 quantisation {cite:dettmers2023qlora}, allowing generators of 3.8 to 7.6 billion parameters to run on a single NVIDIA GeForce RTX 4060 with 8 GB of memory {cite:nvidia_rtx4060}, and the PEFT library provided LoRA {cite:hu2022lora} for the monolithic fine-tuning baseline.

Evaluation combined SciPy {cite:virtanen2020scipy} and scikit-learn {cite:pedregosa2011sklearn} for paired statistical tests and classification metrics, sentence-transformers {cite:reimers2019sbert} for the retrieval baseline, the WASSA 2024 empathy classifier {cite:yang2024hyy33}, and AI judges accessed through the OpenRouter and Groq APIs, with a third judge used for the earlier systems through the Mistral API, all selected from different developers to avoid self-preference bias {cite:panickssery2024}. A Gradio interface was prepared for demonstration on Hugging Face Spaces, the human study was conducted with Google Forms, and all tables and figures in this report were generated from saved experiment outputs by scripts using pandas and matplotlib, so that every reported number can be reproduced.
