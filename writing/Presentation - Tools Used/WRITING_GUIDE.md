## Draft (report paragraph)

The system was built in Python 3.10 with PyTorch 2.5.1 and Hugging Face Transformers 5.16.1, which provide pre-trained encoders (RoBERTa, BERT, ELECTRA) and instruction-tuned decoders (Phi-4-mini, Qwen2.5, Gemma-3) behind one interface, so that design alternatives could be swapped without rewriting code. bitsandbytes 4-bit NF4 quantisation let 3.8-7.6B-parameter generators run on a single 8 GB RTX 4060, and PEFT provided LoRA for the monolithic fine-tuning baseline. Evaluation combined SciPy 1.15.3 and scikit-learn 1.7.2 for paired statistical tests and classification metrics, sentence-transformers for the retrieval baseline, and two AI judges accessed through the OpenRouter and Groq APIs, chosen from different providers to avoid self-preference bias. A Gradio interface was prepared for demonstration on Hugging Face Spaces, the human study was run with Google Forms, and all tables and figures in this report were generated by scripts with pandas and matplotlib so that every number is reproducible from saved outputs.

## Slide outline

| Stage | Tools | Why this choice |

| Training | Transformers Trainer, PEFT (LoRA) | Detector fine-tuning; LoRA baseline |
| Evaluation | SciPy, scikit-learn, WASSA classifier, 3 AI-judge APIs | Paired tests; independent empathy signals |
| Validation | Google Forms human study | Checks the AI judges against people |
| Demo | Gradio on Hugging Face Spaces | Free hosting, browser access for testers |
| Reproducibility | Git, fixed seeds, table/figure scripts | Every number regenerates from saved outputs |
